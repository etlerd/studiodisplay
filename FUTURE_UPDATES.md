# Future Updates & Ideas

This document tracks potential features and enhancements for future consideration.

## Proposed Features

### Video Conferencing Integration
- **Description**: Integrate live video calling capabilities into the player
- **Potential Approaches**:
  - Zoom iframe embed or SDK
  - Google Meet iframe embed
  - Custom WebRTC implementation
  - Jitsi Meet (open-source)
  - Daily.co API
- **Considerations**:
  - Display mode (picture-in-picture, split screen, or full screen toggle)
  - Audio handling (mixing with loop video, sound effects)
  - Keyboard shortcuts for mute/unmute, camera toggle
  - Use cases: live streaming with guests, remote viewing, hybrid presentations
- **Status**: Proposed
