Settings

Recommended: GitHub Releases base path (ends with /)
Example: https://github.com/user/repo/releases/download/studio-display/
Local files: Use file:// format (file:///C:/Users/name/Videos/)
⚠️ SharePoint/OneDrive NOT supported (CORS blocked)
See HOSTING_GUIDE.md for setup instructions
Enter just the filename (will be appended to base path above)
Example: background.mp4 or Motion%20Graphic.mp4
This approach allows numbered videos (01-26) and images (01-10) to work
Advanced: Leave empty and put full URL in directory field (numbered files won't work)
Numbered files: Upload files to your hosting location (e.g., same GitHub Release as your loop video).
Number keys (1-9,0): Display images 01-10 (formats: .png, .jpg, .jpeg, .gif, .webp)
Letter keys (a-z): Play videos 01-26 (formats: .mp4, .mov, .avi, .webm)
Shift+letter (A-Z): Display HTML pages 01-26 from HTML Pages Base URL
Semicolon (;): Return to loop video
Numpad keys 1-8: Play sounds over current media (formats: .mp3, .wav, .m4a)
File naming (GitHub Releases): Use any descriptive name starting with the number:
• Videos: 01-intro.mp4, 02-sermon-clip.mov
• Images: 03-announcement.png, 04-worship-lyrics.jpg
• Sounds: 05-applause.mp3, 06-ding.m4a
HTML pages: Commit to repo html/ folder, name exactly 01.html, 02.html, etc.
⚠️ HTML files in GitHub Releases will download, not display.
⚠️ GitHub Releases do NOT work for HTML files — browsers download them instead of displaying them.
Recommended: Commit HTML files to your repo's html/ folder. They'll be served by GitHub Pages at the same origin.
• Name files exactly: 01.html, 02.html, … 26.html
• Press Shift+A → 01.html, Shift+B → 02.html, etc.
• Leave as ./html/ if your files are in the html/ subfolder of this repo.
• Any CORS-friendly base URL works (e.g. Cloudflare R2 with public access).
Up to 5 one-off HTML page URLs. Press F2–F6 to display them.
Same restriction applies: avoid GitHub Release URLs.
